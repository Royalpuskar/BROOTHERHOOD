# Contributing to Brootherhood

Brootherhood is a team competition project. Ask the repository owner to invite you as a collaborator; do not share passwords or personal access tokens.

1. Create a branch such as `feature/accessibility-update`.
2. Commit original code and clearly document substantive changes.
3. Run `npm test` and check keyboard and mobile interactions.
4. Open a pull request explaining the learning benefit and any accessibility, privacy, or security impacts.
5. Obtain at least one teammate review before merging into `main`.

Never commit secret keys, credentials, copied templates, licensed images without permission, or personal learner information. Avoid external analytics and third-party scripts. Ensure any educational model is clearly labeled when illustrative rather than real-world measurement.

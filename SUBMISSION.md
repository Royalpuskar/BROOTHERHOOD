# BROOTHERHOOD — HORIZON 2026 project submission

## Project name
**BROOTHERHOOD — Discover the Next Dimension**

**Theme:** Quality Education (SDG 4) · Informatics & interactive learning

**Live website:** https://royalpuskar.github.io/BROOTHERHOOD/

**Guided floating 3D demo:** https://royalpuskar.github.io/BROOTHERHOOD/experience/?tour=1

## Project statement

BROOTHERHOOD is a browser-first learning universe that connects original interactive 3D environments, programming and cybersecurity skills, science experiments, and an editable computer-science study roadmap. Learners can travel between nine subject-themed floating islands, practice with real tools, and receive immediate feedback without a mandatory account.

## What to demonstrate to the judges

1. **Homepage:** Cinematic floating 3D archipelago with original branded design and live scene, not a static landing-page screenshot. Show functional global search and animated experience carousel.
2. **3D Universe:** Open the guided tour; stop it, drag to orbit, pinch or scroll to zoom, change lighting/detail settings, and enter a 3D portal.
3. **Programming Studio:** Run C/C++, Python or another supported language through the configured Judge0-compatible external execution service.
4. **Pocket 3D Lab:** Rotate the simplified human-heart model, select labeled chambers/valves/vessels, follow circulation and answer the five-question assessment.
5. **CS Study Lab:** Demonstrate logic truth tables, binary conversion, matrix mathematics, set operations, combinations and BFS on editable graphs. Show customizable local syllabus progress.
6. **Cyber Arena:** Identify threats and safe responses in an interactive cybersecurity mission; show locally saved achievement progress.
7. **Horizon Connect:** View the event dashboard prototype and explain the optional secure FastAPI + SQLAlchemy/MySQL server and QR/AI integrations.

## Implementation and honesty notes

- All homepage UI actions link to working site features. The global search and media showcase are functional.
- Visuals are original 3D procedural geometry, SVG illustration and CSS. No BMW brand identity, logos, or car-company content is used.
- Animation is optional and respects reduced-motion preferences; every major destination has a text-link fallback.
- The published front end is a static GitHub Pages site. Horizon's multi-user APIs are only live when its separately hosted backend is configured. Never claim otherwise in a presentation.
- Code Studio's real compiler service is external and can depend on network/API availability.
- The University Horizon event details in the optional demo dashboard are fictional placeholders, explicitly labeled as demo, not confirmed official schedules.
- Learner progress for the local labs is stored in the browser unless users export it.

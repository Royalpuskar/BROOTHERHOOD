Privacy

Effective date: November 25, 2026

This notice covers the BROOTHERHOOD learning site and the BROOTHERHOOD Learning Guide plugin for ChatGPT.

ChatGPT study guide

The study guide is a skills-only plugin. It does not connect to a BROOTHERHOOD account, server, or database, and it does not send your chat prompts to BROOTHERHOOD. ChatGPT processes conversations under OpenAI's applicable privacy terms and settings.

Learning site

The project README states that the site does not use accounts, email collection, analytics, tracking scripts, advertising networks, or a remote user database. Learning progress is stored in your browser's local storage and is not sent to a BROOTHERHOOD server. You can clear locally stored site data through your browser's settings.

If you choose Run or Test in Pro Code Studio, your code and standard input are sent to the configured Judge0-compatible compiler. The compiler is an external service; its own privacy practices apply. Do not submit passwords, secrets, personal information, or proprietary code.

The site also loads the Three.js renderer from a public CDN. That third-party service is governed by its own terms and privacy practices.

Horizon Connect is documented as a static demonstration unless its separately hosted backend is configured. If that backend or any other data-collecting feature is deployed, this notice must be updated to describe it.

Contact

For privacy questions, contact the project through the BROOTHERHOOD GitHub issue tracker.
